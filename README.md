# 连六棋（Connect Six）

一个使用 **C++17 + EasyX** 编写的 Windows 桌面棋类游戏，支持**双人对战、人机对战、局域网对战**三种模式。

棋盘 19×19，黑棋先行：开局第一回合黑棋落 1 子，之后双方每回合各落 2 子，先连成 6 子（横 / 竖 / 斜，6 子以上也算）者获胜。全部操作用鼠标完成。

> 项目名 / 解决方案：**ifdream-s-games**（工程文件 `ifdream-s-games.vcxproj`）。

## 功能特性

- **双人对战**：同一台电脑上黑白轮流落子，支持悔棋。
- **人机对战**：棋形评分 + 三层递归搜索的 AI；AI 在后台计算，思考期间界面不会卡死。
- **局域网对战**：TCP 直连（默认端口 46888，可自定义），主机执黑；支持落子同步、悔棋协商、再来一局、局内文字聊天。
- **窗口自适配**：窗口可自由拖动缩放，画面等比缩放并留黑边；`F11` 全屏，`Ctrl` + `+` / `Ctrl` + `-` 缩放，`Ctrl` + `0` 复位。
- **无控制台窗口**：Windows 子系统，双击运行只出现游戏窗口。

## 游戏规则

| 项目 | 规则 |
| --- | --- |
| 棋盘 | 19×19 交叉点 |
| 先手 | 黑棋 |
| 每回合落子数 | 通常 2 子；仅开局黑棋第一回合落 1 子 |
| 胜负 | 横、竖、斜任意方向连成 6 子及以上 |
| 和棋 | 棋盘下满仍无人连成 6 子 |

## 运行环境

- Windows 10 / 11
- Visual Studio 2022（「使用 C++ 的桌面开发」工作负载，v143 工具集 + Windows 10 SDK）
- [EasyX](https://easyx.cn) 图形库（2025 版或更新）：
  - 头文件 `graphics.h` / `easyx.h` 安装到 VS 的 `VC\Auxiliary\VS\include`
  - 库文件安装到对应平台的 `VC\Auxiliary\VS\lib`（Unicode 字符集，自动链接 `EasyXw.lib`）

建议使用 **x64** 配置（已按 x64 验证编译）。

## 构建与运行

1. 用 Visual Studio 打开 `ifdream-s-games.sln`；
2. 选择 `Debug | x64` 或 `Release | x64`；
3. 生成解决方案（F7）或直接调试运行（F5）。

生成产物：`x64\Debug\ifdream-s-games.exe`、`x64\Release\ifdream-s-games.exe`。

`assets/` 下的图片资源会在构建时由 `CopyAssets` 目标复制到输出目录，程序按 exe 所在目录定位资源；手动拷贝 exe 时请连同 `assets/` 一起复制。

## 操作说明

- **窗口**：拖动边框缩放；`F11` 全屏 / 窗口切换；`Ctrl` + `+` / `-` 等比缩放，`Ctrl` + `0` 恢复默认大小。
- **主菜单**：点击「双人对战 / 人机对战 / 局域网对战 / 退出游戏」。
- **对局中**：点击棋盘交叉点落子；右侧「悔棋」需在本回合结束后点击（未完成本回合会提示）。
- **退出对局**：点「退出」或按 `Esc` 弹出确认框，只有「继续游戏 / 返回菜单」两项；对局结束界面提供「重新开始 / 返回菜单」。
- **人机对战**：AI 在后台计算（显示「AI思考中...」），期间可点「退出」返回菜单，界面不会卡死。
- **局域网对战**：
  - 主机点「创建房间」，填写监听端口（默认 46888），界面显示本机 IP 与端口；
  - 客户端点「加入房间」，填写主机 IP 与端口（点击输入框或 `Tab` 切换，回车连接，`Esc` 返回）；
  - 对局中按 `回车` 或点击右侧聊天区输入文字，回车发送、`Esc` 取消输入；消息区可用鼠标滚轮或 `PageUp` / `PageDown` 翻看历史（保留最近 200 条）；
  - 悔棋需对方同意；对局结束后可发起「再来一局」。

## 项目结构

```text
ifdream-s-games/
├─ ifdream-s-games.sln / .vcxproj / .vcxproj.filters / .vcxproj.user
├─ assets/                 图片资源（构建时复制到输出目录）
├─ docs/design/            早期设计素材（不参与运行）
├─ tests/run_tests.bat     纯逻辑单元测试（连接参数校验 + 通信帧编解码）
└─ src/
   ├─ main.cpp             入口：加载资源、建窗口、主循环、模式分发
   ├─ core/                本地对局核心：棋盘状态、悔棋、规则与棋形（纯逻辑）
   ├─ ai/                  AI：棋形评估 + 递归搜索
   ├─ ui/                  界面层：显示与缩放、棋盘视图、菜单、面板、对话框、资源
   ├─ modes/               对局流程：双人 / 人机 / 局域网（大厅、会话、共享界面）
   └─ net/                 网络层：协议、TCP 传输、在线对局核心（不依赖界面）
```
